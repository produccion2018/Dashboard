# Insight Hub

Tipo de Proyecto: Dashboard de Métricas y Estadísticas en Tiempo Real

Tecnología: React Chart.js / Recharts Node.js

¿Qué es y qué función cumple?

¿Qué es un Dashboard? Es un panel de control visual que resume y muestra métricas clave de negocio

(ventas, rendimiento, tráfico, etc.) en tiempo real mediante gráficos interactivos (tortas, barras, líneas).

En un entorno profesional, demuestra tu habilidad para transformar datos complejos en interfaces

analíticas intuitivas que los gerentes adoran.

Prompt para desarrollar / generar este proyecto:

Actúa como desarrollador Frontend Senior especializado en UI/UX. Necesito que crees el

código fuente para un Dashboard Ejecutivo (DataFlow) ultra moderno en React utilizando

Tailwind CSS y componentes de gráficos (como Recharts). El panel debe incluir tarjetas

de métricas clave (KPIs con indicadores de crecimiento), un gráfico de líneas de

ventas mensuales, un gráfico de torta de distribución de categorías y una tabla

interactiva de transacciones recientes con paginación., no bakend  solo diseño usa app y componente
